# Para Nerea ❤️

Web de cumpleaños hecha con HTML, CSS y JavaScript.

## Cómo verla
1. Abre `index.html` en tu navegador.
2. Para personalizarla, edita los textos de `index.html`.

## Cómo añadir tus fotografías
1. Abre la carpeta `images`.
2. Sustituye `foto1.png`, `foto2.jpg`, `foto3.jpg` y `foto4.jpg` por tus fotos.
3. Puedes añadir más tarjetas copiando uno de los bloques `<figure class="photo-card ...">` y cambiando la imagen y el texto.

Consejo: usa copias de las fotos, no las únicas originales. Para que la web cargue rápido, intenta que cada foto pese menos de 1–2 MB.

## Publicarla gratis con GitHub Pages
1. Sube los archivos al repositorio desde GitHub Desktop.
2. En GitHub, abre el repositorio y entra en **Settings**.
3. En el menú lateral, abre **Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/(root)`, y pulsa **Save**.
6. Espera un momento: GitHub mostrará la dirección pública de tu web en esa misma sección.

Antes de compartir el enlace, comprueba que estás cómodo con todas las fotos y textos que serán visibles públicamente.
